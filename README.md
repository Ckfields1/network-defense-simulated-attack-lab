# Defending a Network from a Simulated Attack

## Overview

This repository documents a hands-on network security lab I completed as part of my Network Security, Firewalls, and VPNs course. The lab simulated attacks against vulnerable systems and demonstrated how security professionals identify vulnerabilities, remove malicious files, patch systems, and strengthen network defenses.

## Tools and Technologies

* Infection Monkey
* Metasploit Framework
* Windows Security Antivirus
* Linux
* Bash
* Firewall management
* DMZ security controls

## Lab Activities

During this lab, I:

* Used Infection Monkey to simulate an attack against a vulnerable web server.
* Reviewed vulnerability findings and security recommendations.
* Observed how files could be transferred to a compromised system.
* Used antivirus software to locate and remove malicious test files.
* Configured a Metasploit exploit against a vulnerable Linux server.
* Successfully obtained a Linux command shell in an authorized lab environment.
* Identified the vulnerable Bash version installed on the target.
* Patched the system and confirmed that the Bash version was updated.
* Verified that the original exploit no longer worked after patching.
* Used Windows Security to detect an EICAR antivirus test file.
* Updated DMZ firewall rules to strengthen the network perimeter.

## Skills Demonstrated

* Vulnerability assessment
* Penetration-testing fundamentals
* Network-defense analysis
* Metasploit configuration
* Malware detection
* Patch management
* Firewall configuration
* DMZ hardening
* Remediation validation
* Linux command-line usage

## Key Takeaway

This lab demonstrated the complete security cycle of identifying a vulnerability, safely exploiting it in a controlled environment, applying remediation, and verifying that the remediation prevented the attack from succeeding again.
